# 南怀瑾著作证据型 RAG 工作台

这是一个本地静态版的“证据优先”RAG 原型，用来减少大模型在南怀瑾先生相关内容上的幻觉。

它不自带任何著作文本。请只导入你合法拥有、可用于个人研究的 TXT 或 Markdown 文本。

## 使用方法

1. 打开 `index.html`。
2. 在左侧导入 `.txt` 或 `.md` 文件。
3. 可在“资料库”中查看已导入作品。
4. 在检索框中输入问题或关键词，例如：
   - `人体重要气脉`
   - `任督二脉`
   - `中脉`
   - `气脉和修持`
5. 右侧会返回：
   - 最相关的原文片段
   - 文件名、章节线索、片段编号
   - 可复制给大模型的“证据约束提示词”

## 设计原则

- 只基于本地导入资料检索，不联网抓取。
- 找不到就明确显示“当前资料库没有明确证据”。
- 回答区域不会把检索不到的内容强行补全。
- 区分“当前资料库未找到”和“南先生从未说过”。

## 检索方式

当前版本使用浏览器内运行的混合检索：

- 中文/英文关键词匹配。
- 字符 n-gram 相似度。
- 章节标题与作品名加权。
- 命中词高亮。

后续可以扩展为：

- 后端 SQLite FTS5 + 向量数据库。
- OpenAI embeddings 或本地 embedding 模型。
- reranker 重排。
- 接入 LLM 后只允许根据引用片段回答。

## 建议的资料整理格式

TXT/MD 文件中最好保留章节标题，例如：

```text
# 静坐修道与长生不老

## 第一章

原文……

## 气脉问题

原文……
```

这样检索结果能显示更准确的出处线索。
